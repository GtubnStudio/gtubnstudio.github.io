\### 软件介绍



Gtubnmium 是由 Gtubn Studio 倾力打造的官方网站专用桌面客户端。项目基于 Electron 框架构建，专为提升 Web 端的桌面化沉浸体验而设计。



客户端深度集成了无边框现代窗口、自定义导航顶栏以及单实例运行功能。同时，软件内嵌入了原生关于信息弹窗、外置默认浏览器跳转及缓存动态清理机制，为您带来更流畅、更安全且契合原生 Windows 风格的专属浏览体验。
